## Student Management System

### Overview
A comprehensive student management application built using OOP principles.

### Components
- **models.py** - Data models for students, attendance, and grades
- **repository.py** - Data persistence layer (CSV storage)
- **service.py** - Business logic layer
- **main.py** - CLI entry point

### Installation
```bash
pip install -e .
```

### Usage
```bash
python -m student_management.main
```
