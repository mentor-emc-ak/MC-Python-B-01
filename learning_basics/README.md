# Learning Basics

This directory contains all Python learning scripts and exercises organized by topic and progression.

## Files Overview

### Fundamentals
- `one.py` - Basic programming concepts
- `two.py` - Additional basic exercises

### Data Structures
- `list_set_tuple.py` - Comprehensive guide to lists, sets, and tuples

### Control Flow & Functions
- `day_7.py` - Day 7 practice exercises
- `example.py` - Various Python examples

### Advanced Topics
- `learn_decorators.py` - Understanding Python decorators and their applications

### File Handling
- `file_handling.py` - Reading and writing files, CSV operations
- `calculator.py` - Calculator application with file storage
- `data.csv` - Sample CSV data for file handling exercises
- `example.txt` - Text file examples

### Mini Projects
These are complete mini-projects demonstrating practical applications:

1. **mini_project_1.py** - First project
2. **mini_project_2.py** - Second project  
3. **mini_project_3.py** - Third project (Student Management System prototype)

## How to Use

Run any script directly:
```bash
python script_name.py
```

Or use from within the project:
```bash
cd learning_basics
python calculator.py
```
