# User Stories

**Project:** MarketPlace API
**Format:** As a [role], I want [feature] so that [benefit].

---

## Epic 1: Authentication & Onboarding

| ID | Story | Priority |
|---|---|---|
| US-001 | As a new user, I want to register with email/password via Firebase so that I can access the platform | Must Have |
| US-002 | As a user, I want to log in with Google SSO so that I don't have to manage a separate password | Should Have |
| US-003 | As a user, I want my profile created automatically on first login so that I don't have to fill a separate form | Must Have |
| US-004 | As a user, I want to update my display name, avatar, and shipping addresses so that my profile stays current | Must Have |
| US-005 | As a buyer, I want to register as a seller so that I can list my own products | Must Have |

## Epic 2: Product Discovery

| ID | Story | Priority |
|---|---|---|
| US-010 | As a guest, I want to browse products without logging in so that I can evaluate the platform before registering | Must Have |
| US-011 | As a buyer, I want to search products by keyword so that I can find what I'm looking for quickly | Must Have |
| US-012 | As a buyer, I want to filter products by category, price range, and rating so that I see only relevant results | Must Have |
| US-013 | As a buyer, I want to sort results by price, newest, or top-rated so that I can compare options easily | Should Have |
| US-014 | As a buyer, I want to view a product detail page with images, description, price, and reviews so that I can make an informed purchase decision | Must Have |
| US-015 | As a buyer, I want to see in-stock status on product listings so that I don't add out-of-stock items to my cart | Must Have |

## Epic 3: Seller Product Management

| ID | Story | Priority |
|---|---|---|
| US-020 | As a seller, I want to create a new product listing with name, description, price, stock, and images so that buyers can find and purchase it | Must Have |
| US-021 | As a seller, I want to update my product details so that the listing stays accurate | Must Have |
| US-022 | As a seller, I want to delete a product listing so that discontinued items are removed | Must Have |
| US-023 | As a seller, I want to assign products to categories so that buyers can discover them through browsing | Must Have |
| US-024 | As a seller, I want to view my sales history and revenue so that I can track my business performance | Should Have |

## Epic 4: Cart & Checkout

| ID | Story | Priority |
|---|---|---|
| US-030 | As a buyer, I want to add products to my cart so that I can collect items before purchasing | Must Have |
| US-031 | As a buyer, I want to update quantities or remove items in my cart so that I can adjust my order | Must Have |
| US-032 | As a buyer, I want to see a cart summary with item prices and total so that I know what I'll pay | Must Have |
| US-033 | As a buyer, I want to checkout my cart and create an order so that my purchase is confirmed | Must Have |
| US-034 | As a buyer, I want to receive an order confirmation notification so that I have a record of my purchase | Must Have |

## Epic 5: Order Management

| ID | Story | Priority |
|---|---|---|
| US-040 | As a buyer, I want to view my order history so that I can track past purchases | Must Have |
| US-041 | As a buyer, I want to see order status updates (confirmed, shipped, delivered) so that I know where my package is | Must Have |
| US-042 | As a buyer, I want to cancel a pending order so that I can change my mind before it ships | Should Have |
| US-043 | As a seller, I want to view incoming orders for my products so that I can fulfill them | Must Have |
| US-044 | As a seller, I want to update order status to shipped so that buyers are notified | Must Have |

## Epic 6: Reviews & Ratings

| ID | Story | Priority |
|---|---|---|
| US-050 | As a buyer with a delivered order, I want to leave a star rating and written review so that I can share my experience | Must Have |
| US-051 | As a buyer, I want to see all reviews for a product so that I can assess its quality | Must Have |
| US-052 | As a seller, I want to see reviews for my products so that I can understand buyer feedback | Should Have |
| US-053 | As an admin, I want to flag and remove abusive reviews so that the platform stays trustworthy | Must Have |

## Epic 7: Notifications

| ID | Story | Priority |
|---|---|---|
| US-060 | As a buyer, I want to receive an in-app notification when my order status changes so that I'm always informed | Must Have |
| US-061 | As a buyer, I want to receive an email when my order is confirmed so that I have a receipt | Should Have |
| US-062 | As a user, I want to manage my notification preferences so that I only receive alerts I care about | Could Have |

## Epic 8: Admin

| ID | Story | Priority |
|---|---|---|
| US-070 | As an admin, I want to view and manage all users so that I can resolve account issues | Must Have |
| US-071 | As an admin, I want to promote a user to seller or admin role so that I can manage platform access | Must Have |
| US-072 | As an admin, I want to see a moderation queue of flagged products and reviews so that I can keep the platform clean | Must Have |
